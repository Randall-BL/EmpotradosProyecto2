# CD-09 — Interfaz de visualización

- **Responsable:** A · **Fecha:** 2026-11-05 · **Estado:** decidido
- **Requisito:** mostrar título, artista, álbum, duración, número de canción / total,
  estado y filtro activo en LCD, VGA o TFT (§3-F p.4, §3-SIS p.6).

## Alternativas

| | A. VGA + Character Buffer (catálogo) | B. Controlador VGA de texto propio en HDL | C. LCD/TFT externo |
|---|---|---|---|
| Hardware extra | ninguno: conector VGA de la tarjeta | ninguno | módulo LT24/LTM + cableado (no confirmado) |
| Esfuerzo | bajo: IP del University Program | alto: temporización, ROM de fuentes, DMA de texto | medio-alto: driver del panel |
| Interfaz para el software | escribir un byte ASCII en (x, y): `base + (y << 7) + x` | igual, pero hay que diseñarla y verificarla | comandos por SPI/paralelo |
| Recursos | Video PLL + ≈ 8 KB de M10K + lógica de video | similares | depende del panel |
| Riesgo | bajo: IP probado en DE1-SoC | alto | alto (disponibilidad) |

El enunciado solo exige HDL propio para el filtro DSP; la visualización "puede controlarse
por hardware dedicado o software" (§3-SIS p.6), así que un IP de catálogo es válido.

## Decisión

**Alternativa A.** Cadena de video:
`char_buf` (Character Buffer for VGA Display, 80 × 60) → `video_fifo` (Dual-Clock FIFO,
50 → 25 MHz) → `vga` (VGA Controller, 640 × 480 @ 60 Hz), con `video_pll` a 25 MHz.
El Nios V escribe los caracteres por puntero directo (`CHAR_BUF_BASE + (y << 7) + x`) y
limpia la pantalla con el bit R del registro de control; nada de HAL.

## Boceto de la pantalla (80 × 60, filas 0–14)

```
+------------------------------------------------------------------------------+
| REPRODUCTOR DE AUDIO - CE1113                              Cancion  03 / 12   |
|------------------------------------------------------------------------------|
| Titulo : Nombre de la cancion                                                 |
| Artista: Nombre del artista                                                   |
| Album  : Nombre del album                                                     |
| Duracion: 03:45                    Transcurrido: 01:12                        |
|                                                                              |
| Estado : > REPRODUCIENDO             Filtro: PASA-BAJOS (SW1)                 |
| Volumen: [##########----------] 50%                                          |
|------------------------------------------------------------------------------|
| KEY0 Play/Pausa  KEY1 Stop  KEY2 Anterior  KEY3 Siguiente   SW: filtro       |
+------------------------------------------------------------------------------+
```

## Consecuencias

- **HW-09:** `video_pll`, `char_buf`, `video_fifo` y `vga` en `build_system.tcl`; pines
  `VGA_*` en el `.qsf`.
- **NV-11:** driver `vga_text` (`vga_text_clear`, `vga_text_put`, `vga_text_print`) y la
  pantalla del boceto.
- **Si se consigue un LCD/TFT en el laboratorio:** se evalúa el LT24 Controller del
  catálogo con la misma interfaz `vga_text_*` hacia la aplicación.
